# Aital Graphics — Design Your Vision

## About the Project
Aital Graphics is my personal graphic design portfolio website. It showcases my creative designs and projects online in a modern and professional way.

## Website Sections
- **Home:** Introduces my website, logo, and tagline.
- **About:** Provides information about Aital Graphics.
- **Portfolio:** Displays my graphic design projects in image cards.
- **Services:** Presents the design services offered by Aital Graphics.
- **Skills:** Highlights my graphic designing skills.
- **Contact:** Allows visitors to contact me for inquiries and projects.

## Technologies Used
- HTML5
- CSS3

## Color Palette
- **Black:** Represents power and a premium, professional look.
- **Golden:** Represents luxury and creativity.
- **White:** Represents simplicity and readability.

## Features
- Modern and professional design
- Portfolio cards showcasing creative work
- Responsive layout for different screen sizes
- Contact section for visitors

## Project Goal
The goal of this project is to showcase my graphic design work online and demonstrate my web development skills.
